## 3️⃣ MELD-Emo — Multimodal Emotion & Sentiment Recognition

> **`PyTorch` · `BERT` · `Whisper` · `ResNet`**

An end-to-end multimodal deep learning system for conversational video analysis across **text, audio, and visual** inputs.

### 🧠 Highlights

- 🎯 Jointly processed **text, audio, and visual modalities** using the MELD dataset.
- ⚡ Built a **multi-process caching pipeline** with `ProcessPoolExecutor`.
- 🚀 Increased GPU utilization from **20% to 90%+** by removing CPU-bound decoding bottlenecks.
- 🧠 Implemented **singleton-based lazy loading** for model artifacts.
- 💾 Eliminated OOM crashes and enabled **instant API readiness** in production.
- 📈 Improved rare-emotion detection using **inverse class-frequency weighting** in `CrossEntropyLoss`.
